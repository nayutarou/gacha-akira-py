## 🌟 アピールポイント

このプロジェクトで特に見てほしい、こだわって実装した点は以下の通りです。

### 1. 網羅的で品質の高いテストコード

品質を最も重視し、`pytest`を活用した多角的なテストを実装しました。

- **多様なテストシナリオ**: 正常系だけでなく、確率分布の妥当性(`test_distribution.py`)、境界値(`test_boundary.py`)、予期せぬエラーへの耐性(`test_error_handling.py`)、そして性能(`test_performance.py`)まで、様々な観点からテストを行っています。
- **高い可読性と保守性**: `conftest.py`で共通処理をまとめるなど、テストコード自体の可読性やメンテナンス性も意識して設計しています。

これにより、機能追加やリファクタリングを安心して行える、堅牢なコードベースを実現しました。

### 2. CI/CDによる開発プロセスの自動化

開発の効率と信頼性を高めるため、CircleCIを用いたCI/CDパイプラインを構築しました。

- **継続的インテグレーション**: プッシュやプルリクエストをトリガーに、テストやビルドが自動的に実行され、コードの品質を常に高く保ちます。 (`.circleci/config.yml`)
- **依存関係の自動更新**: Dependabot (`dependabot.yml`) を設定し、ライブラリの脆弱性に迅速に対応できる体制を整えています。

これらの自動化により、開発者は安心して機能開発に集中できます。

### 3. シンプルで拡張性の高い設計思想

長く使われることを目指し、シンプルさと拡張性を両立する設計を心がけました。

- **関心の分離**: ガチャのコアロジック(`gacha.py`)、CLIのエントリーポイント(`main.py`)、Web APIサーバー(`server.py`)、設定(`settings.py`)を明確に分離しています。
- **柔軟な実行環境**: 同じコアロジックを、コマンドラインツールとしてもWeb APIとしても利用できる、柔軟な構成になっています。

これらの設計により、将来的な機能拡張や仕様変更にも容易に対応可能です。
